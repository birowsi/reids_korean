레육계 DS 한글 패치 v6 (번역 검수/패처 안전성 보강판)

Windows용. ZIP의 파일을 모두 같은 폴더에 풀어 주세요.
  Korean_Patcher.exe
  korean_patch_v6.dat
  xdelta3.exe

사용 방법
1. 본인이 보유한 지원 대상 일본어 원본 ROM을 준비합니다.
2. 원본 ROM 이름을 original.nds로 바꿔 패처 폴더에 넣은 뒤
   Korean_Patcher.exe를 실행합니다.
   또는 이름을 바꾸지 않고 원본 ROM을 실행 파일로 끌어 놓습니다.
3. PIN 0314를 입력합니다.
4. 성공하면 패처 폴더에 rei.nds가 만들어집니다.

주의 사항
- 입력 파일 이름이 패처 폴더의 rei.nds이면 거부됩니다.
- 지원 대상 원본/결과 ROM은 SHA-256으로 검사합니다.
- 실패하면 원본 및 기존 rei.nds를 보존합니다.
- 성공하면 기존 rei.nds가 새 결과물로 교체됩니다.
- 원본 ROM은 이 패키지에 포함하지 않습니다.
- 비공식 비상업용 패치입니다. 실제 플레이 전체 QA는 미실시입니다.
